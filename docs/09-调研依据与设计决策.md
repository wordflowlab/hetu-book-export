# 调研依据与设计决策

固定仓库、提交、许可与已读文件见[来源记录](research/sources.json)。参考源码已逐个克隆为research base，原包不作为运行依赖；未把上游声明或测试数量视为河图运行证据。朗读与书稿交付由现有创作旅程推导，专用能力通过格式标准和真实制品验证。

编译以固定纯文本正文、明确脚注和插图为输入。PDF使用随包OFL中文字体并按实际字形检查；EPUB保留目录与资源清单。富文本、排版或资源不能表示时必须显式损失或失败，不默默丢章。

采用TypeScript纯领域、应用服务、React审阅和公开SDK四层。共享技术栈不代表DSH原包兼容；不复制其内置Agent、模型连接或第二份正文库。代码独立实现，实际引入的库、字体及共享SDK各自保留许可和摘要。

字体库1.1.1的UMD产物含旧Babel原型访问。构建仅对固定输入SHA的18处继承赋值及1处读取替换为标准Object方法，保留许可、变更说明与前后摘要；不修改node_modules，不放宽Node25的原型禁用、文件、网络或子进程限制。scripts/fontkit-compatibility.mjs及随包兼容回执是补丁事实源。

## 中文PDF字形的实际验证

逐页渲染曾发现子集字体缺字，而字形存在检查与PDF页数正常。根因为旧fontkit选择short loca时右移奇数偏移，截断未对齐的glyf轮廓。随包静态字体以fontTools4.68.0规范为四字节对齐，保留字符覆盖、轮廓和OFL；转换脚本、输入输出摘要及修改说明随源码和包保留，不扩大运行权限，不依赖作者安装Python。

回归读取实际PDF中的FontFile2，逐一解码子集轮廓，并检查混排断行及七页长稿的真实渲染；结构、文本内容和视觉各自取证。
